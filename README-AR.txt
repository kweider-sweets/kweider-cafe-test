تحديث نظام Kweider Rewards — نسخة جاهزة للرفع
================================================

طريقة الاستخدام:
1) فك ضغط الملف.
2) انسخ جميع الملفات والمجلد assets إلى داخل مشروعك الحالي:
   D:\GitHub\kweider-cafe-test
3) وافق على استبدال الملفات الموجودة.
4) افتح GitHub Desktop ثم Commit ثم Push origin.
5) افتح صفحة الموظف وصفحة العميل بعد دقيقتين، ثم حدّث الصفحة تحديثاً قوياً.

أهم التعديلات:
- ربط صفحة الموظف بنظام المكافآت الجديد الفعلي بدلاً من مكافأة £5 القديمة.
- اختيار المكافأة المتاحة بالاسم وتاريخ الانتهاء.
- حساب خصم 3% أو 5% تلقائياً مع تطبيق الحد الأقصى الصحيح.
- دعم مكافأة الفطور لشخصين دون اشتراط مبلغ شراء.
- رقم الإيصال في الاستبدال اختياري، والخادم ينشئ مرجعاً تلقائياً عند تركه فارغاً.
- الاستبدال لا يخصم النقاط؛ تتغير حالة المكافأة إلى Redeemed فقط.
- عرض المكافآت المتاحة بوضوح في بطاقة العميل.
- إصلاح بنية HTML في قسم Messages & Rewards.
- دعم أسماء الحقول بنظام camelCase و snake_case لزيادة الثبات.
- تحديث Service Worker إلى الإصدار v3.4.0 لتفادي بقاء النسخة القديمة في الهاتف.
- تصحيح Manifest ID ليعمل بصورة صحيحة على GitHub Pages والدومين الخاص.
- إزالة اعتماد شارة الصفحة الرئيسية على نظام النقاط المحلي القديم.

اختبار مقترح:
- العميل QR Test لديه 50 نقطة ومكافأة 3%.
- من صفحة الموظف اختر 3% Off.
- أدخل مبلغ شراء £20.00.
- يجب أن يظهر الخصم £0.60.
- بعد الاستبدال تبقى النقاط 50 وتصبح المكافأة Redeemed.

ملاحظة:
- إضافة نقاط الشراء ما زالت عملية منفصلة عن استبدال المكافأة، حتى لا يتم احتساب نقاط البيع المخفّض بطريقة غير متفق عليها.
- ملف assets/js/loyalty-service.js ملف تجريبي قديم وغير مستخدم بواسطة صفحات Supabase الحالية.
